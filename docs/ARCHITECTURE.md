# Architecture

The architecture document is maintained as a single, rendered HTML page:

### → [`architecture.html`](architecture.html)

Open it in a browser — it's self-contained and works offline. It covers the design invariants,
the ingest → store → core → adapters flow, the normalized-schema contract, security &amp; auth, the
repository layout, licensing, and the three-chapter roadmap.
